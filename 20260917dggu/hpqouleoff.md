# 祝贺！这项中医整脊疗法，成功入选江苏省中医药特色疗法

> 更新时间：2026-09-17 (UTC+8)

近日，江苏省中医药管理局正式公布全省中医药特色疗法入选结果，东南大学附属中大医院中医骨伤科主任屈留新主任医师牵头申报的技术**“中医整脊疗法”**成功入选江苏省中医药特色疗法。**

中医整脊疗法**

**01**

**以手为术 以脊为纲**

中医整脊疗法，是以脊椎解剖学、生物力学、影像学为基础，用手来纠正脊柱的不正常位置或状态来治疗脊柱疾病及脊柱相关疾病的方法，以达到消除人体疾患，恢复健康的目的，是中医正骨疗法的一种，也是用来治疗脊椎及相关性疾病的一种方法。

**02**

**名师传承 匠心治学**

东南大学附属中大医院中医骨伤科，早在上世纪七十年代初因独特的中医整脊疗法而名扬海内外。为了推广该项诊疗技术，南京市曾组织南京市中医骨伤、推拿科医生来中大医院中医骨伤科接受中西医结合骨伤科专家张朝纯教授的培训。该项诊疗技术吸引很多国内外本专业人士前来进修学习。

**03**

**守正创新 国际传扬**

中医整脊疗法、中医正骨疗法是中医骨伤科确有疗效的传统治疗方法，由张朝纯教授担任主编、屈留新主任担任副主编的《脊柱疾病手法治疗学》，详细地总结了中医整脊手法的诊治经验。屈留新主任主编的《中医整脊》（东南大学出版社）进一步《脊柱疾病手法治疗学》《中医整脊》详细描述了中医整脊/中医正骨的手法技术操作规范。

近年来，屈留新主任多次赴国外讲学，推广中医整脊技术，推动了中医骨伤科的国际文化交流。
