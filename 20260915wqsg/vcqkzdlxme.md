# 霉菌性阴道炎预防忌饮酒 念珠菌阴道炎传染吗

> 更新时间：2026-09-15 (UTC+8)

**霉菌性预防忌饮酒**

做好霉菌性阴道炎预防，可以避免疾病造成更多的伤害，也可以避免疾病蔓延，专家指出霉菌性阴道炎预防，小事不可忽视，其中就包括戒酒戒烟、少吃辛辣食物等。

霉菌性阴道炎不宜吃的食物：

1、禁食发物。如鱼类、虾、蟹、鸡头、猪头肉、鹅肉、鸡翅、鸡爪等，食后会加重阴部的瘙痒和炎症。

2、尽量少吃辛辣、刺激的食物。例如：洋葱、胡椒、辣椒、花椒、芥菜、茴香。

3、避免吃油炸、油腻的食物。如油条、奶油、黄油、巧克力等，这些食物有助湿增热的作用，会增加白带的分泌量，不利于病情的治疗。

4、戒烟戒酒。烟酒刺激性很强，会加重炎症。

做到霉菌性阴道炎预防，可以避免疾病的并发症，要求大家在把握了霉菌性阴道炎预防方法的时候，一定要积极的到专业的医院治疗这种疾病，以保证大家的安全和健康。

**念珠菌阴道炎传染吗**

念珠菌是阴道的一个正常菌群，当病人在疫力低下，或全身疾病、全身用药，或者不洁的性关系、或者阴道过度冲洗的时候，可以导致阴道的菌群失调，念珠菌大量繁殖，从而发生念珠菌性的阴道炎。常常表现为阴道或外阴的瘙痒、性交痛，排尿时可能会有外阴的灼热感，白带多、黄色豆渣状分泌物。念珠菌性的阴道炎，也常称为霉菌性阴道炎，是可以通过性关系传播的，有的偶尔也会有外源性的传播。治疗时最好是男女双方同时治疗。

儿童阴道炎怎么治疗

如果是家长患有阴道炎，例如霉菌性阴道炎和孩子一定要分开进行洗漱，尤其是浴盆和浴巾之类的一定要分开，避免发生交叉感染后治疗起来更加困难。小孩阴道炎通常是因为卫生清洁不到位导致的，需要及时到医院做分泌物检查，明确病原体后在医生指导下局部用药治疗，例如克霉唑。另外，平时要每天给孩子换洗内裤，最好将内裤放在太阳下暴晒，饮食上尽量避免让孩子吃辛辣、刺激性的食物。严重的需要同时配合口服药物治疗，例如制霉菌素片，因为儿童比较小，一定要禁止乱用抗生素治疗，一定要按照医嘱用药，时间不易过长。

孕期阴道炎反反复复

对于孕期反复霉菌性阴道炎发作者，建议遵医嘱用药，但以局部用药为主，以小剂量长疗程为佳，一般可以应用7到14天，禁止服用唑类抗真菌药物，如氟康唑或者米糠唑。因反复发作这种情况，一般建议阴道分泌物真菌培养，同时行药敏实验，根据药敏选择合适的抗真菌药物，治疗期间应定期复查监测疗效，并注意药物的副作用。如果出现耐药或者副作用应立即停药，更换其它类型的药物。治疗结束后7到14日建议追踪复查，如果治疗后仍复发，可再次做真菌培养并行药敏试验，并在治疗的第三个月及第六个月进行真菌培养。

**霉菌性阴道炎可完全治愈吗**

女性因为不良的卫生习惯，不洁的性生活，过度的流产，乱使用抗生素等，以及患有糖尿病或妊娠女性容易患上霉菌性阴道炎。

有的女性患上此病在治疗好了以后又一而再的复发，遭受反反复复的困扰。为此，女性想要完全治愈此病，女性在治疗期间应该注意以下事项：

第一、夫妻双方应该同时接受治疗，如果仅女方治疗而男方未治，那么即使女方治愈也会被丈夫再感染，使念珠菌在夫妻双方间反复“传递”，女性的霉菌性阴道炎反复出现。

第二、在治疗期间不吃喊糖分高的食物，即使霉菌性阴道炎治愈以后有要少吃，也不宜食用辛辣刺激性食品。

第三、治疗时积极用药治疗，力求彻底根治。即使治疗完以后，仍需要在每次月经干净后去医院复查妇科检查及阴道分泌物化验，连续3次。如果此期间有1次又发现念珠菌感染迹象就不能定为痊愈，而属于复发或再感染，需要继续治疗。

第四、在治疗期间或平时，最好注意个人卫生，勤换内裤，用过的内裤、盆、毛巾等应用开水烫洗，并在治疗期间禁止性生活。

霉菌性阴道炎可完全治愈吗？想要完全治愈霉菌性阴道炎，在治疗最好遵循以上治疗原则，避免霉菌性阴道炎反反复复发作，带给人无尽的烦劳。治疗霉菌性阴道炎需要选择一家正规的妇科医院，在医生的指导下进行规范治疗，并且一定要按疗程治疗。
