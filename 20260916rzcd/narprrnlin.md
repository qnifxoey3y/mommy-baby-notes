# 读懂遗传 “密码”，守护宝宝健康 “起跑线”

> 更新时间：2026-09-16 (UTC+8)

亲爱的准父母朋友们，当您满心期待迎接新生命时，遗传因素却可能像隐藏在暗处的 “小插曲”，影响生育进程。今天，我们就结合大家可能遇到的实际情况，聊聊遗传那些事儿。

一、这些情况，可能和遗传有关

（一）反复流产背后的染色体 “警报”

张女士和丈夫备孕两年，经历了 3 次自然流产。每次怀孕都在孕早期突然终止，这让他们痛苦又迷茫。来院检查后发现，丈夫是染色体平衡易位携带者。这类染色体结构异常，就像 “隐形炸弹”，携带者本人通常无症状，但在孕育过程中，胚胎染色体容易出现数目或结构问题，导致流产。临床上，约 50% 的早期自然流产，其胚胎可能存在各种形式的染色体异常。

（二）常见的单基因遗传病

单基因遗传病，就像藏在基因里的 “小开关”，一旦这个 “开关” 因突变出现异常，就可能引发疾病。它们遵循孟德尔遗传规律，由单个基因的改变导致。虽然这些疾病在人群中的发病率可能不算高，但对患者及其家庭的影响却不容忽视。接下来，我们通过甲型血友病和成人型多囊肾这两个典型例子，一起了解单基因遗传病的遗传规律与潜在风险。

**1.甲型血友病：**李女士家族中，舅舅和弟弟都患有甲型血友病，这是一种典型的 X 染色体连锁隐性遗传病。甲型血友病患者体内缺乏凝血因子XIII，轻微创伤就可能导致出血不止，严重时甚至危及生命。通常男性患病，女性以携带者为多见，女性患者少见。李女士的母亲作为携带者，将携带致病基因的X染色体遗传给了李女士的弟弟使其发病，而李女士有50%的概率为携带者。若李女士也继承了其母亲的携带致病基因的那条X染色体，她在生育后代时，儿子患病/健康的概率各有 50%；女儿有 50% 的概率成为携带者，另50%概率为健康。

**2.成人型多囊肾：**王先生和父亲都患有成人型多囊肾，这是一种常染色体显性遗传病。随着年龄增长，患者肾脏会出现多个囊肿，逐渐破坏肾脏功能，最终可能发展为肾衰竭。只要父母一方存在相应基因变异，子女就有 50% 的概率遗传该变异。

（三）家族史带来的多基因遗传疾病风险

刘女士家族中，奶奶、父亲都患有高血压，她备孕时就格外担忧。高血压是一种多基因遗传病，受多个基因和环境因素的共同影响，若家族中有长辈患病，后代在不健康的生活方式下，其患病风险增加；若家族中多人患病，意味着患病风险进一步增加。

二、哪些情况下，备孕夫妇需要考虑遗传学检查？

（一）有家族史

如果夫妇任一方的家族成员中有一人或多人出现可能与遗传疾病相关的异常表现，建议尽量先对患者做遗传学检查，找出病因后，再对有备孕需求的夫妇行针对性的遗传学检查。

（二）存在不良孕产史

像经历过反复流产、胚胎停育、胎儿畸形或死胎等不良孕产情况的夫妇，遗传学检查必不可少。就像前面提到的张女士，多次自然流产后通过检查发现丈夫染色体平衡易位。通过染色体核型分析、基因检测等手段，能排查出胚胎发育异常是否由遗传因素导致，为后续备孕提供科学依据。

（三）特殊职业或环境暴露人群

如果夫妇双方或一方长期从事化工、放射性物质相关工作，或在生活中经常接触甲醛、苯、农药等有害物质，以及长期处于高辐射环境，这些因素可能会影响生殖细胞的遗传物质，增加胎儿遗传疾病的发生风险。这类人群在备孕时，建议进行全面的遗传学检查，评估遗传风险。

（四）有亲缘关系

《中华人民共和国民法典》中明确规定，禁止直系血亲及三代以内旁系血亲结婚。有血缘关系的亲属之间携带相同致病基因的概率较高，这会增加隐性遗传病的发病风险，在备孕前一定要进行详细的遗传学咨询和基因检测，排查可能存在的遗传隐患。

（五）普通备孕夫妇

对于普通备孕夫妇来说，扩展性携带者筛查是一种科学、有效的孕前或产前健康管理方式。该筛查通过检测父母双方是否携带有某些隐性遗传病的致病基因，评估胎儿罹患这些遗传病的风险。虽然大多数携带者本身没有症状，但如果夫妇双方为同一致病基因的携带者，其子女则有25%的概率患病。扩展性携带者筛查可以一次性检测几十上百种常见遗传病，帮助夫妇提前了解潜在风险，从而做出更科学的生育决策。

三、遇到遗传问题，该如何应对？

（一）健康生活，降低潜在风险

备孕夫妇都要远离烟酒，避免接触甲醛、辐射等有害物质。像从事化工行业的准父母，更要做好职业防护。合理饮食、适量运动，肥胖的备孕夫妇科学减重，能改善宝宝的健康状况。尤其对于有高血压等多基因遗传病家族史的夫妇来说，多基因遗传病没有有效的生殖干预方法，最好的预防方法就是身体力行，减少环境因素的负面影响。

（二）辅助生殖，精准筛选胚胎

对于有明确遗传风险的夫妇，以植入前胚胎遗传学检测技术为核心的辅助生殖助孕是健康生育的希望。它可以通过活检胚胎，来筛选和剔除染色体异常胚胎或有相应遗传疾病发病风险的胚胎，降低流产率或出生缺陷风险。

（三）规范检查，把握关键节点

对于遗传概率低或表现轻微的遗传疾病，备孕夫妇可以选择自然怀孕，必要时产前诊断。尤其对于有不良孕育史的夫妇，一旦再次怀孕，整个孕期的检查环环相扣，严格遵循医嘱，才能及时发现潜在风险。

四、常见误区

（一）家里没有遗传病就不用做遗传学检查

很多人认为家族中没有遗传病史，就无需进行遗传学检查，这是一种常见的认知偏差。一方面，隐性遗传病需要夫妇双方均为致病基因携带者，才可能在子代发病，即使家族中从未出现过患病案例，夫妇双方仍有可能携带致病基因；另一方面，基因突变可能在个体发育过程中随机发生，与家族病史并无关联。因此，孕前或孕期的遗传学检查十分必要。

（二）经过胚胎植入前遗传学检测（PGT）筛选的胚胎就是最健康的，可以高枕无忧

PGT技术并非能检测所有的遗传疾病，目前它只能针对已知的特定致病基因或染色体异常进行检测，检测范围以外的基因或染色体异常、新发突变的风险与一般人群相似。而且，PGT检测技术存在技术局限性，孕期的常规产检不能忽视，行业规范建议PGT助孕者妊娠后需做羊水穿刺明确胎儿情况。

生育之路或许会遇到遗传问题的阻碍，但现代医学有多种手段保驾护航。我们会根据您的具体情况，制定个性化方案，陪您一起跨越难关。河北医科大学第二医院生殖医学科是我省首例PGT宝宝的诞生地，如果您有任何疑问，随时与我们沟通，我们期待和您共同迎接健康新生命的到来！
